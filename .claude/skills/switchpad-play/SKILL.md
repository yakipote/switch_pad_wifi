# switchpad で Switch 2 を操作する

配信を見ている人にも分かるように、**操作の前に `say` で一言しゃべってから押す**のが基本。

## 1. 始める前に

1. `status` を呼ぶ
   - タイムアウトする → 常駐サーバーか MCP プロセスの問題。ユーザーに `make status` を頼み、3 つとも OK なら Claude の再起動をお願いする
   - `usb_ready: false` → Switch がスリープ中。ユーザーに起こしてもらう
   - `capture.error` が空でない → `make start`（または `make voice`）をお願いする
2. `screenshot` で今の画面を見て、どこにいるかを短く `say` する
3. スリープ復帰直後の「A つづける」画面では HOME が効かない。A で進むと HDR の案内が出ることがあるので、十字キー左で「あとで」→ A。そのあと HOME（`b13`）でホームメニューに戻れる

## 2. 操作のループ

1回の操作は次の形にする。

1. `say("〇〇を開きます")` … これから何をするか、なぜかを 1 文で。20〜40 字くらい。長い説明はしない
2. `press_and_look` で押して画面を確認（メニュー操作はほぼこれ 1 つで済む）
3. 結果を見て、思った画面でなければ `say("あれ、△△になった。戻ります")` と言ってから立て直す

- 同じ方向に何回も動かすときは、毎回 `say` しなくてよい。まとまりごとに 1 回
- 結果を見なくてよい連打は `press`。コマンド技などタイミングが大事な入力は `sequence`
- `set_state` で押しっぱなしにしたら、終わったら必ず `rest`
- 作業の区切り・終了時にも `rest` を送る

### say の例

| 場面 | say |
|---|---|
| 最初 | 「HOME 画面にいます。ストリートファイター6 を起動します」 |
| メニュー移動 | 「設定を開いて、コントローラーの項目を探します」 |
| 迷ったとき | 「思っていた画面と違うので、一度 B で戻ります」 |
| ゲーム中 | 「波動拳を撃ちます。↓↘→＋パンチ」 |
| 終わり | 「トレーニングモードに入れました。ここで止めます」 |

## 3. 入力の名前

| 名前 | ボタン |
|---|---|
| `b1` A / `b2` B / `b3` X / `b4` Y | 決定は A、戻るは B |
| `b5` L / `b6` R / `b11` ZL / `b12` ZR | |
| `b7` − / `b8` + / `b13` HOME / `b14` キャプチャー | |
| `b9` / `b10` | 左 / 右スティック押し込み |
| `p1` | 十字キーの角度：0 上、90 右、180 下、270 左（45 刻み）、-1 で離す |
| `a1` `a2` / `a4` `a5` | 左 / 右スティック X・Y（-1〜1、右と上がプラス） |

例：`press_and_look({"p1": 90})` で右、`press_and_look({"b1": 1}, wait_ms=1200)` で決定して画面が変わるのを待つ。

## 4. 画面を見るときのコツ

- `screenshot` の `max_width` は 640 まで。それより大きいと返ってこないことがある
- 小さい文字は `crop`（1920x1080 の座標で `[x, y, w, h]`）で切り出して読む
- 画面が切り替わるのが遅い場面（ソフトの起動など）は `wait_ms` を 2000〜5000 にするか、`screenshot` を撮り直す

## 5. 1P になっていないとき

メニューは動くのにゲーム内でキャラが動かないときは、このコントローラーが 1P になっていない。

1. `say("コントローラーを 1P に登録し直します")`
2. HOME（`b13`）→ 下の「コントローラー」→「持ちかた/順番を変える」
3. その画面で `press({"b5": 1, "b6": 1})`（L+R 同時）
4. A で決定してゲームに戻る

## 6. 必ず守ること

- **セーブデータの削除・上書き、初期化、購入、ユーザー設定の変更など、取り消せない確認画面では押す前に止まってユーザーに確認する**。`say` だけで済ませない
- ニンテンドー eShop で購入につながるボタンは押さない
- オンライン対戦・ランクマッチでは自動操作しない。そういう画面に入りそうなら止めて確認する
- 何をしているか分からなくなったら、B で戻るか HOME に戻ってから `screenshot` で立て直す
